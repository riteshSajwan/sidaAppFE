# Environment Variables

This project reads the following variables from `.env`.

## Current Example

```env
EXPO_PUBLIC_API_BASE_URL='https://taxiappsaas.findnerd.com'
EXPO_PUBLIC_WEBSOCKETCONNECTION_BASE_URL='wss://taxiappsaas.findnerd.com/ws/order/admin'
EXPO_PUBLIC_SUPPORT_CHAT_DOMAIN='webinar.findnerd.com'
EXPO_PUBLIC_IS_SAAS=true
EXPO_PUBLIC_IS_INTERCITY=true
```

## Variables

### `EXPO_PUBLIC_API_BASE_URL`

Base API URL used for authentication and other backend requests.

Example:

```env
EXPO_PUBLIC_API_BASE_URL='https://taxiappsaas.findnerd.com'
```

### `EXPO_PUBLIC_WEBSOCKETCONNECTION_BASE_URL`

WebSocket URL used for admin order updates.

Example:

```env
EXPO_PUBLIC_WEBSOCKETCONNECTION_BASE_URL='wss://taxiappsaas.findnerd.com/ws/order/admin'
```

### `EXPO_PUBLIC_SUPPORT_CHAT_DOMAIN`

Domain used for support chat configuration.

Example:

```env
EXPO_PUBLIC_SUPPORT_CHAT_DOMAIN='webinar.findnerd.com'
```

### `EXPO_PUBLIC_IS_SAAS`

Controls SaaS-only features.

Values:

- `true`: show SaaS-enabled UI/features
- `false`: hide SaaS-only UI/features

### `EXPO_PUBLIC_IS_INTERCITY`

Controls Intercity features.

Values:

- `true`: show the Intercity tab and related popup
- `false`: hide the Intercity tab and related popup

## Notes

- Restart the app/dev server after changing `.env` values.
- Keep quotes consistent with the existing `.env` style.
